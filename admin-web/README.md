# BazMart Admin Web Portal (Phase 3)

## Overview
The BazMart Admin Portal is a responsive web dashboard built with **Next.js 15 (App Router)**, **Tailwind CSS**, and **shadcn/ui**. It provides operations, inventory, catalog, and fleet managers with real-time controls over the BazMart platform.

## Core Capabilities
- **Dark Store Live Operations:** Real-time order picking, packing queue, and delivery dispatch statuses.
- **ERP & Catalog Management:** Product catalog overrides, pricing rules, promotional banner management, and ERP sync monitors.
- **Rider Fleet Telemetry:** Interactive live map tracking riders across Kurdistan Region & Iraq urban delivery zones.
- **Financial & COD Reconciliation:** Daily cash-on-delivery collection reconciliations by courier and warehouse branch.
